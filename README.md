# AZ-900 Smart Quiz (Unofficial)

A mobile-first practice quiz for learners preparing for the Azure Fundamentals (AZ-900) exam. Built for the PLP "Vibe Coding Hackathon: AZ-900 Exam Prep Edition".

> **Unofficial study tool.** This project is not affiliated with or endorsed by Microsoft. All questions are original and written for this project.

## What it does

- 10 original practice questions across cloud concepts, Azure architecture, and security and governance

- Instant feedback after every answer, with an explanation and a reason why each wrong option is wrong

- Options are shuffled every attempt

- Score summary with a per-topic breakdown and a review of missed questions

## In progress

- Saving attempts and a history view (Supabase)

- "Explain it simply" button powered by Claude, through a server-side Edge Function

## Tech stack

React, TypeScript (strict), Vite, Tailwind CSS, shadcn/ui

## Run locally

```

npm install

npm run dev

```
